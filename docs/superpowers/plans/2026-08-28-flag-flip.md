# Flag flip: STRUCTURED_BATCH_EXTRACTION — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Switch the nightly scraper to post-level structured extraction (owner approved 2026-08-28), watch exactly one night against a captured baseline, and revert on any quality regression.

**Architecture:** No code change. One env line on the server + a gunicorn restart flips the gate in `c_admin/scraper.py` (`STRUCTURED_BATCH_EXTRACTION`, read at import). The legacy path stays in the code; removing the line restores it. Quality is judged by comparing the first structured night's rows to the three legacy nights captured below.

**Tech Stack:** Django on EC2 (gunicorn), `.env.local`, existing crons (scrape 21:01 UTC, dedupe 03:37 UTC).

## Global Constraints

- Mutation window 03:00–20:30 UTC; run `/home/ubuntu/misc/preflight.sh` first. The flip must land BEFORE 21:01 UTC to take effect tonight.
- **Never stop/reboot the instance.** gunicorn restart only.
- Rollback is the removal of one line + restart; take a `.env.local` backup first.
- Owner approved the recurring cost on the basis of "a couple dollars more per month" (measured: legacy ≈ $19/month, structured ≈ $20–24/month). If the first night's spend implies materially more, report it, do not silently continue.
- Nothing in this plan touches the DB directly.
